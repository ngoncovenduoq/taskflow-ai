# TaskFlow AI

An AI-powered productivity assistant built with Python, FastAPI, LangChain, and Google Gemini.

## Features

- Create tasks using natural language
- List and manage tasks with AI tool calling
- REST API using FastAPI

## Tech Stack

Python | FastAPI | LangChain | Gemini API

## Getting Started

1. Navigate to the `backend` directory.
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file with your `GOOGLE_API_KEY`.
4. Run: `python -m uvicorn main:app --reload`
5. Open `http://127.0.0.1:8000/docs`
